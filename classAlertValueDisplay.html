Detailed Description

Specialized ValueDisplay that changes text color based on low/high threshold comparisons.

AlertValueDisplay inherits from ValueDisplay and provides an automatic tri-state color-alerting mechanism based on configurable low and high thresholds.

Operating Threshold Zones

  • Low Alert Zone (value < mLowThreshold): Renders the numerical value in mLowColor (e.g. Blue for cold engine coolant or low fuel pressure).
  • Normal Zone (mLowThreshold <= value < mHighThreshold): Renders the numerical value in mNormalColor (e.g. Green for safe operating conditions).
  • High Alert Zone (value >= mHighThreshold): Renders the numerical value in mHighColor (e.g. Red for overheating, overpressure, or redline conditions).

All other features (title, formatted string, measurement unit, cursor blinking, background rendering) are fully inherited from ValueDisplay.

Example Usage

#include <ValueDisplay/AlertValueDisplay.h>
#include <font/Ubuntu_14_B.h>
#include <font/Ubuntu_20_B.h>
AlertValueDisplay tempGauge;
void setupTempGauge(void)
{
// 1. Configure geometry, framebuffer, and LCD brush
tempGauge.setFrameBuffer(brush);
tempGauge.setLcd(lcd);
tempGauge.setArea({10, 90, 130, 60});
tempGauge.setBgColor(0x20, 0x20, 0x20);
// 2. Configure title, value box, and unit
tempGauge.setTitleConfig(Font_Ubuntu_14_B, {5, 5}, Color{0xAA, 0xAA, 0xAA}, "COOLANT");
tempGauge.setValueConfig(Font_Ubuntu_20_B, {5, 25, 80, 30}, {2, 5},
Color{0x00, 0xFF, 0x00}, Color{0x10, 0x10, 0x10}, "%3.0f");
tempGauge.setUnitConfig(Font_Ubuntu_14_B, {90, 25, 35, 30}, Color{0xFF, 0xFF, 0xFF}, "'C");
// 3. Set alert thresholds: Low < 50.0'C, High >= 105.0'C
tempGauge.setAlertValue(50.0f, 105.0f);
// 4. Set alert colors: Blue (cold), Green (normal), Red (overheat)
tempGauge.setAlertColor(Color{0x00, 0x80, 0xFF}, Color{0x00, 0xFF, 0x00}, Color{0xFF, 0x00, 0x00});
// 5. Draw static background
tempGauge.drawBackground();
}
void updateTemperature(float coolantTemp)
{
// 6. Draw value (color updates automatically depending on coolantTemp)
tempGauge.drawValue(coolantTemp);
}

AlertValueDisplay::AlertValueDisplay ( )

Constructs a new AlertValueDisplay object with default thresholds (10 / 90) and colors.

Initializes an AlertValueDisplay instance with default threshold values and standard alert colors. The default normal color is set to green (RGB: 0x00, 0xFF, 0x00), low alert color to blue (RGB: 0x00, 0x00, 0xFF), and high alert color to red (RGB: 0xFF, 0x00, 0x00). The default low threshold is set to 10.0f and the high threshold to 90.0f.

◆ drawValue()

void AlertValueDisplay::drawValue ( float value)
overridevirtual

Evaluates the value against thresholds to select the appropriate alert color, then renders it.

Parameters
[in]valueThe floating-point value to display.

Evaluates the provided numerical value against the configured low and high threshold limits:

  • If value < mLowThreshold: mValueColor is set to mLowColor (low alert state).
  • If mLowThreshold <= value < mHighThreshold: mValueColor is set to mNormalColor (normal state).
  • If value >= mHighThreshold: mValueColor is set to mHighColor (high alert state).

After determining the active text color, it invokes ValueDisplay::drawValue(value) to perform formatting, off-screen rendering, and display blitting.

Parameters
[in]valueThe floating-point value to evaluate and display.
