Detailed Description

Widget for drawing a horizontal progress bar indicator.

ProgressDisplay is a dedicated progress visualization widget that displays a horizontal progress bar representing values between 0.0% and 100.0%.

Visual Layout

  • Outer Background: Filled with mBgColor across the entire widget area.
  • Track Groove: Inset by 5 pixels on all sides (top, bottom, left, right) and filled with mProgressBgColor.
  • Active Bar: Drawn inside the track groove starting from the left edge, with its width proportional to (value / 100.0f) * trackWidth and filled with mProgressColor.

Value Protection

Input values passed to drawValue() are automatically clamped between 0.0f and 100.0f to prevent visual glitches and buffer overruns.

Example Usage (from Touch Calibration Application)

#include <ValueDisplay/ProgressDisplay.h>
void pageDisplayTouchCalibration(void*)
{
ProgressDisplay progressBar;
ElapsedTime pressTime;
// 1. Associate off-screen buffer and LCD drawing surface
progressBar.setFrameBuffer(brush);
progressBar.setLcd(lcd);
// 2. Set widget area and colors
progressBar.setArea({50, 200, 140, 30});
progressBar.setBgColor(0x30, 0x30, 0x30);
progressBar.setColor(Color{0x30, 0xFF, 0x30}, Color{0x80, 0x80, 0x80});
// 3. Render initial background and empty progress bar (0%)
progressBar.drawBackground();
progressBar.drawValue(0);
// 4. Update progress dynamically in a loop or callback
while (calibrating)
{
int32_t elapsedMs = (int32_t)pressTime.getMsec();
float progressPercent = (float)elapsedMs / 50.0f; // 0 to 100% over 5000 ms
lcd.lock();
progressBar.drawValue(progressPercent);
lcd.unlock();
thread::yield();
}
}

ProgressDisplay::ProgressDisplay ( void )

Constructs a new ProgressDisplay object with default colors.

Initializes a ProgressDisplay instance with default colors:

  • Outer widget background: dark-gray (RGB: 0x30, 0x30, 0x30)
  • Active progress indicator: bright green (RGB: 0x30, 0xFF, 0x30)
  • Track/groove background: medium-gray (RGB: 0x80, 0x80, 0x80)

Internal pointers to the off-screen frame buffer and display surface brush are initialized to nullptr.

void ProgressDisplay::drawBackground ( )
overridevirtual

Renders the outer widget background and the empty progress track groove.

Renders the static widget background and the un-filled progress track. It configures the frame buffer to match the entire widget area, clears it with the outer background color (mBgColor), draws an inner groove rectangle using mProgressBgColor with a 5-pixel inset margin on all sides, and blits the complete background bitmap to the LCD display.

Implements BaseDisplay.

◆ drawValue()

void ProgressDisplay::drawValue ( float value)
overridevirtual

Renders the progress bar filling proportional to the given percentage value.

Parameters
[in]valueProgress percentage value (clamped between 0.0f and 100.0f).

Clamps the provided value between 0.0f and 100.0f to prevent visual rendering artifacts or overflow outside the allocated boundaries. It calculates the inner progress bar area by applying a 5-pixel margin on all four sides of the widget area.

The method then:

  1. Resizes the frame buffer to the inner track dimensions.
  2. Clears it with the groove background color (mProgressBgColor).
  3. Computes the active bar width proportional to the percentage (value / 100.0f * totalWidth).
  4. Draws a solid filled rectangle with the active progress color (mProgressColor).
  5. Blits the composited progress bar bitmap onto the target LCD at the offset position.
Parameters
[in]valueCurrent progress percentage, clamped between 0.0f and 100.0f.

Implements BaseDisplay.
