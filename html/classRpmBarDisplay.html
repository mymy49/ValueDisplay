Detailed Description

Widget displaying engine RPM as a segmented colored bar and a colored top guideline.

RpmBarDisplay is an automotive-style tachometer gauge widget designed to visualize engine revolutions per minute (RPM). It combines a static multi-colored top guideline bar with a dynamically filling bar underneath.

Dual-Bar Architecture

  1. Top Segmented Guideline: Drawn across the top with a thickness of mToplineThickness pixels. It remains statically divided into four color segments proportional to their respective operating RPM zones:
    • Idle Zone (0 ~ mIdleRpm): Rendered in mIdleColor (Default: Blue).
    • Normal Zone (mIdleRpm ~ mWarningRpm): Rendered in mNormalColor (Default: Green).
    • Warning Zone (mWarningRpm ~ mOverRpm): Rendered in mWarningColor (Default: Yellow).
    • Over-rev / Redline Zone (mOverRpm ~ mMaxRpm): Rendered in mOverColor (Default: Red).
  2. Dynamic RPM Bar: Positioned beneath the top guideline and inset by 3 pixels horizontally. Its width expands proportionately to (value / mMaxRpm) * trackWidth. The bar's color dynamically switches to match the active zone that the current RPM falls into.

Example Usage

#include <ValueDisplay/RpmBarDisplay.h>
RpmBarDisplay tachometer;
void setupTachometer(void)
{
// 1. Associate off-screen buffer and LCD surface
tachometer.setFrameBuffer(brush);
tachometer.setLcd(lcd);
// 2. Configure bounding area and background colors
tachometer.setArea({20, 40, 200, 35});
tachometer.setBgColor(Color{0x00, 0x00, 0x00}); // Outer bezel background
tachometer.setBarBgColor(Color{0x25, 0x25, 0x25}); // Dynamic bar track background
// 3. Configure full-scale RPM and top guideline thickness
tachometer.setMaxRpm(8000);
tachometer.setToplineThickness(4);
// 4. Customize zone colors (optional; standard defaults are already set)
tachometer.setIdleColor(Color{0x00, 0x80, 0xFF}); // Blue
tachometer.setNormalColor(Color{0x00, 0xFF, 0x00}); // Green
tachometer.setWarningColor(Color{0xFF, 0xFF, 0x00}); // Yellow
tachometer.setOverColor(Color{0xFF, 0x00, 0x00}); // Red
// 5. Draw static background and top guideline segments
tachometer.drawBackground();
}
void updateEngineSpeed(float currentRpm)
{
// 6. Update dynamic RPM bar (e.g. 4500 RPM will display in Green)
tachometer.drawValue(currentRpm);
}

RpmBarDisplay::RpmBarDisplay ( void  )

Constructs a new RpmBarDisplay object with default thresholds (1100, 5000, 6000, 8000 RPM) and colors.

Initializes the RPM bar gauge with default automotive tachometer thresholds and color schemes:

  • Idle RPM threshold: 1100 RPM (Color: Blue, RGB: 0x00, 0x00, 0xFF)
  • Warning RPM threshold: 5000 RPM (Color: Green, RGB: 0x00, 0xFF, 0x00)
  • Over-rev RPM threshold: 6000 RPM (Color: Yellow, RGB: 0xFF, 0xFF, 0x00)
  • Maximum RPM scale: 8000 RPM (Color: Red, RGB: 0xFF, 0x00, 0x00)
  • Top guide line thickness: 5 pixels
  • Background color: Black (RGB: 0x00, 0x00, 0x00)
  • Bar groove background color: Dark gray (RGB: 0x30, 0x30, 0x30)

Internal pointers to the off-screen frame buffer and LCD drawing brush are initialized to nullptr.

void RpmBarDisplay::drawBackground ( )
overridevirtual

Renders the widget background and the segmented top reference guideline.

Renders the widget background and the segmented top reference guideline. The top reference guideline is partitioned into four colored segments proportional to their respective RPM ranges relative to mMaxRpm:

  1. Idle segment: width proportional to mIdleRpm / mMaxRpm, drawn in mIdleColor.
  2. Normal segment: width proportional to (mWarningRpm - mIdleRpm) / mMaxRpm, drawn in mNormalColor.
  3. Warning segment: width proportional to (mOverRpm - mWarningRpm) / mMaxRpm, drawn in mWarningColor.
  4. Over-rev segment: width proportional to (mMaxRpm - mOverRpm) / mMaxRpm, drawn in mOverColor.

Once all segments are rendered into the off-screen frame buffer, the composited background is transferred to the LCD surface.

◆ drawValue()

void RpmBarDisplay::drawValue ( float  value)
overridevirtual

Renders the dynamic RPM bar filled proportionally to the given RPM value.

Parameters
[in]valueCurrent engine RPM value.

Renders the dynamic RPM bar filled proportionally to the given RPM value.

The method performs the following steps:

  1. Computes the inner bar area with a 3-pixel horizontal margin on each side and vertically positioned beneath the top reference guideline (offset by mToplineThickness + 6).
  2. Clears the bar area with mBarBgColor.
  3. Calculates the active bar width as (value / mMaxRpm) * totalWidth.
  4. Determines the fill brush color based on current RPM zone:
    • value < mIdleRpm: mIdleColor
    • value < mWarningRpm: mNormalColor
    • value < mOverRpm: mWarningColor
    • value >= mOverRpm: mOverColor
  5. Fills the dynamic bar rectangle and blits the resulting bitmap directly onto the target LCD surface at the appropriate screen coordinates.
Parameters
[in]valueCurrent engine RPM value to display.
