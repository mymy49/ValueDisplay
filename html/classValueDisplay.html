Detailed Description

Display widget capable of rendering a formatted numeric value, unit label, title, and interactive cursor blinking.

ValueDisplay extends BaseDisplay to provide a complete, modular gauge widget suitable for instruments, sensor readouts, dashboards, and numeric input editing dialogs.

Key Features

  • Title Label: Displays an identifier string (e.g. "SPEED", "VOLTAGE") at an arbitrary position offset.
  • Formatted Value: Formats floating-point numbers using standard sprintf format specifiers (e.g. "%3.1f", "%02.0f"), rendered inside its own sub-box area.
  • Measurement Unit: Displays the measurement unit suffix (e.g. "km/h", "V", "°C") aligned at the bottom-left of the configured unit area.
  • Cursor Blinking Support: drawValueWithCursor() enables cursor editing visualization by periodically replacing a character at a specified index with a space character when the cursor is off.
  • Selective Refreshing: drawValue() redraws only the numerical value sub-box, avoiding costly full-widget repaints on every value update.

Example Usage

#include <ValueDisplay/ValueDisplay.h>
#include <font/Ubuntu_14_B.h>
#include <font/Ubuntu_20_B.h>
ValueDisplay speedGauge;
void setupSpeedGauge(void)
{
// 1. Associate working framebuffer, target LCD surface, and bounding geometry
speedGauge.setFrameBuffer(brush);
speedGauge.setLcd(lcd);
speedGauge.setArea({10, 20, 130, 60});
speedGauge.setBgColor(0x20, 0x20, 0x20);
// 2. Configure title label ("SPEED" at top-left)
speedGauge.setTitleConfig(Font_Ubuntu_14_B, {5, 5}, Color{0xAA, 0xAA, 0xAA}, "SPEED");
// 3. Configure formatted value sub-box (white text on dark background)
speedGauge.setValueConfig(Font_Ubuntu_20_B, {5, 25, 80, 30}, {2, 5},
Color{0xFF, 0xFF, 0xFF}, Color{0x10, 0x10, 0x10}, "%3.0f");
// 4. Configure measurement unit label ("km/h")
speedGauge.setUnitConfig(Font_Ubuntu_14_B, {90, 25, 35, 30}, Color{0x80, 0xFF, 0x80}, "km/h");
// 5. Draw static background, title, and unit box
speedGauge.drawBackground();
}
void updateSpeed(float currentSpeed)
{
// 6. Dynamically update the displayed number
speedGauge.drawValue(currentSpeed);
}
void updateEditingValue(float targetValue, uint8_t cursorIndex, bool cursorBlinkState)
{
// 7. Update value with blinking cursor indicator during numeric entry
speedGauge.drawValueWithCursor(targetValue, cursorIndex, cursorBlinkState);
}

ValueDisplay::ValueDisplay ( )

Constructs a new ValueDisplay object with default values and styles.

Initializes a new ValueDisplay instance. It sets internal pointers for the working frame buffer, LCD drawing surface brush, and fonts (value, unit, title) to nullptr to prevent invalid memory dereferences before explicit configuration. It sets the default background color to dark-gray (RGB: 0x30, 0x30, 0x30), and clears the unit and title character buffers with zeroes.

void ValueDisplay::drawBackground ( )
overridevirtual

Renders the static background, title label, and unit string onto the LCD.

Renders the static visual elements of the widget, including the overall widget background, the optional title text, and the unit label sub-box. The operation resizes the off-screen frame buffer, clears it with the background color, draws the title if configured, transfers the composited bitmap to the LCD, and subsequently draws the unit sub-box if its dimensions are non-zero.

Formats and renders the given floating-point value onto the LCD.

Parameters
[in]valueThe floating-point value to be displayed.

Formats the given floating-point number into a string buffer according to the configured format string (mFormat). Then it resizes the off-screen frame buffer to match mValueArea, clears it with mValueBgColor, renders the formatted string using mValueFont, and blits the resulting bitmap directly onto the target LCD at the calculated absolute screen coordinates.

Formats and renders the numerical value with an optional cursor blink effect at a specified character index.

Parameters
[in]valueThe floating-point value to display.
[in]index0-based character index within the formatted string where the cursor is placed.
[in]onTrue to display the character normally; false to replace it with a space for blink effect.

Formats the given floating-point value into a string using mFormat and applies a cursor blinking effect at a specific character position (index).

If on is false and index is within the valid length of the formatted string, the character at that index is replaced with an ASCII space (' '), simulating a blinking cursor. The resulting string is then rendered into the off-screen frame buffer and transferred to the LCD at the widget's value area position.

Parameters
[in]valueThe floating-point numerical value to format.
[in]indexCharacter position in the formatted string (0-based) where the cursor blinks.
[in]onBlink phase state: true to render the character normally, false to hide it (blank).
