\doxysubsection{Detailed Description}
Specialized \doxylink{classValueDisplay}{Value\+Display} that changes text color based on low/high threshold comparisons. 

{\ttfamily \doxylink{classAlertValueDisplay}{Alert\+Value\+Display}} inherits from {\ttfamily \doxylink{classValueDisplay}{Value\+Display}} and provides an automatic tri-\/state color-\/alerting mechanism based on configurable low and high thresholds.\hypertarget{classAlertValueDisplay_autotoc_md0}{}\doxysubsubsubsection{\texorpdfstring{Operating Threshold Zones}{Operating Threshold Zones}}\label{classAlertValueDisplay_autotoc_md0}

\begin{DoxyItemize}
\item \texorpdfstring{$\ast$}{*}\texorpdfstring{$\ast$}{*}\+Low Alert Zone ({\ttfamily value \texorpdfstring{$<$}{<} m\+Low\+Threshold})\texorpdfstring{$\ast$}{*}\texorpdfstring{$\ast$}{*}\+: Renders the numerical value in {\ttfamily m\+Low\+Color} (e.\+g. Blue for cold engine coolant or low fuel pressure).
\item \texorpdfstring{$\ast$}{*}\texorpdfstring{$\ast$}{*}\+Normal Zone ({\ttfamily m\+Low\+Threshold \texorpdfstring{$<$}{<}= value \texorpdfstring{$<$}{<} m\+High\+Threshold})\texorpdfstring{$\ast$}{*}\texorpdfstring{$\ast$}{*}\+: Renders the numerical value in {\ttfamily m\+Normal\+Color} (e.\+g. Green for safe operating conditions).
\item \texorpdfstring{$\ast$}{*}\texorpdfstring{$\ast$}{*}\+High Alert Zone ({\ttfamily value \texorpdfstring{$>$}{>}= m\+High\+Threshold})\texorpdfstring{$\ast$}{*}\texorpdfstring{$\ast$}{*}\+: Renders the numerical value in {\ttfamily m\+High\+Color} (e.\+g. Red for overheating, overpressure, or redline conditions).
\end{DoxyItemize}

The default normal color is set to green (RGB\+: 0x00, 0x\+FF, 0x00), low alert color to blue (RGB\+: 0x00, 0x00, 0x\+FF), and high alert color to red (RGB\+: 0x\+FF, 0x00, 0x00).
