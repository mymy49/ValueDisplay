\doxysubsection{Detailed Description}
Abstract base class providing common geometry, framebuffer, and drawing interfaces for display widgets. 

The {\ttfamily \doxylink{classBaseDisplay}{Base\+Display}} class serves as the core foundation for visual UI indicators within the Turtle\+Ship GUI framework (e.\+g. {\ttfamily \doxylink{classValueDisplay}{Value\+Display}}, {\ttfamily \doxylink{classProgressDisplay}{Progress\+Display}}, {\ttfamily \doxylink{classRpmBarDisplay}{Rpm\+Bar\+Display}}).\hypertarget{classBaseDisplay_autotoc_md2}{}\doxysubsubsubsection{\texorpdfstring{Rendering Architecture}{Rendering Architecture}}\label{classBaseDisplay_autotoc_md2}
This class uses an off-\/screen double-\/buffering architecture to eliminate visual screen flickering\+:
\begin{DoxyEnumerate}
\item Off-\/screen Rendering\+: Graphical components are first rendered into a working {\ttfamily Frame\+Buffer} ({\ttfamily m\+Fb}).
\item Blitting\+: Once rendering is complete, the resulting bitmap is transferred to the physical LCD display surface via a {\ttfamily Brush} ({\ttfamily m\+Lcd}).
\end{DoxyEnumerate}\hypertarget{classBaseDisplay_autotoc_md3}{}\doxysubsubsubsection{\texorpdfstring{Key Responsibilities}{Key Responsibilities}}\label{classBaseDisplay_autotoc_md3}

\begin{DoxyItemize}
\item Geometry Management\+: Stores and manipulates widget boundaries, screen coordinates, width, and height via {\ttfamily m\+Area}.
\item Style Management\+: Manages base background fill color ({\ttfamily m\+Bg\+Color}).
\item Surface Binding\+: Connects to off-\/screen buffer ({\ttfamily m\+Fb}) and screen output brush ({\ttfamily m\+Lcd}).
\item Virtual Pipeline\+: Enforces implementation of {\ttfamily \doxylink{classBaseDisplay_a0a14a702c2df4739c58e4ab08facaf99}{draw\+Background()}} and {\ttfamily \doxylink{classBaseDisplay_af5b3bffb81f612b55dc86045b3d51db7}{draw\+Value()}} across all derived widgets.
\end{DoxyItemize}\hypertarget{classBaseDisplay_autotoc_md4}{}\doxysubsubsubsection{\texorpdfstring{Typical Derived Implementation Example}{Typical Derived Implementation Example}}\label{classBaseDisplay_autotoc_md4}
