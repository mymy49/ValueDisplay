\doxysubsection{Detailed Description}
Widget for drawing a horizontal progress bar indicator. 

{\ttfamily \doxylink{classProgressDisplay}{Progress\+Display}} is a dedicated progress visualization widget that displays a horizontal progress bar representing values between 0.\+0\% and 100.\+0\%.\hypertarget{classProgressDisplay_autotoc_md5}{}\doxysubsubsubsection{\texorpdfstring{Visual Layout}{Visual Layout}}\label{classProgressDisplay_autotoc_md5}

\begin{DoxyItemize}
\item {\bfseries{Outer Background}}\+: Filled with {\ttfamily m\+Bg\+Color} across the entire widget area.
\item {\bfseries{Track Groove}}\+: Inset by 5 pixels on all sides (top, bottom, left, right) and filled with {\ttfamily m\+Progress\+Bg\+Color}.
\item {\bfseries{Active Bar}}\+: Drawn inside the track groove starting from the left edge, with its width proportional to {\ttfamily (value / 100.\+0f) \texorpdfstring{$\ast$}{*} track\+Width} and filled with {\ttfamily m\+Progress\+Color}.
\end{DoxyItemize}\hypertarget{classProgressDisplay_autotoc_md6}{}\doxysubsubsubsection{\texorpdfstring{Value Protection}{Value Protection}}\label{classProgressDisplay_autotoc_md6}
Input values passed to {\ttfamily \doxylink{classProgressDisplay_aaff00d2530e2a899527a813c5dabab1a}{draw\+Value()}} are automatically clamped between {\ttfamily 0.\+0f} and {\ttfamily 100.\+0f} to prevent visual glitches and buffer overruns.\hypertarget{classProgressDisplay_autotoc_md7}{}\doxysubsubsubsection{\texorpdfstring{Example Usage (from Touch Calibration Application)}{Example Usage (from Touch Calibration Application)}}\label{classProgressDisplay_autotoc_md7}

Renders the outer widget background and the empty progress track groove. 

Renders the static widget background and the un-\/filled progress track. It configures the frame buffer to match the entire widget area, clears it with the outer background color (m\+Bg\+Color), draws an inner groove rectangle using m\+Progress\+Bg\+Color with a 5-\/pixel inset margin on all sides, and blits the complete background bitmap to the LCD display.

Renders the progress bar filling proportional to the given percentage value. 


\begin{DoxyParams}[1]{Parameters}
\mbox{\texttt{ in}}  & {\em value} & Progress percentage value (clamped between 0.\+0f and 100.\+0f).\\
\hline
\end{DoxyParams}
Clamps the provided value between 0.\+0f and 100.\+0f to prevent visual rendering artifacts or overflow outside the allocated boundaries. It calculates the inner progress bar area by applying a 5-\/pixel margin on all four sides of the widget area.

The method then\+:
\begin{DoxyEnumerate}
\item Resizes the frame buffer to the inner track dimensions.
\item Clears it with the groove background color (m\+Progress\+Bg\+Color).
\item Computes the active bar width proportional to the percentage (value / 100.\+0f \texorpdfstring{$\ast$}{*} total\+Width).
\item Draws a solid filled rectangle with the active progress color (m\+Progress\+Color).
\item Blits the composited progress bar bitmap onto the target LCD at the offset position.
\end{DoxyEnumerate}
