\doxysubsection{Detailed Description}
Widget displaying engine RPM as a segmented colored bar and a colored top guideline. 

{\ttfamily \doxylink{classRpmBarDisplay}{Rpm\+Bar\+Display}} is an automotive-\/style tachometer gauge widget designed to visualize engine revolutions per minute (RPM). It combines a static multi-\/colored top guideline bar with a dynamically filling bar underneath.\hypertarget{classRpmBarDisplay_autotoc_md9}{}\doxysubsubsubsection{\texorpdfstring{Dual-\/\+Bar Architecture}{Dual-Bar Architecture}}\label{classRpmBarDisplay_autotoc_md9}

\begin{DoxyEnumerate}
\item {\bfseries{Top Segmented Guideline}}\+: Drawn across the top with a thickness of {\ttfamily m\+Topline\+Thickness} pixels. It remains statically divided into four color segments proportional to their respective operating RPM zones\+:
\begin{DoxyItemize}
\item {\bfseries{Idle Zone}} ({\ttfamily 0 \texorpdfstring{$\sim$}{\string~} m\+Idle\+Rpm})\+: Rendered in {\ttfamily m\+Idle\+Color} (Default\+: Blue).
\item {\bfseries{Normal Zone}} ({\ttfamily m\+Idle\+Rpm \texorpdfstring{$\sim$}{\string~} m\+Warning\+Rpm})\+: Rendered in {\ttfamily m\+Normal\+Color} (Default\+: Green).
\item {\bfseries{Warning Zone}} ({\ttfamily m\+Warning\+Rpm \texorpdfstring{$\sim$}{\string~} m\+Over\+Rpm})\+: Rendered in {\ttfamily m\+Warning\+Color} (Default\+: Yellow).
\item {\bfseries{Over-\/rev / Redline Zone}} ({\ttfamily m\+Over\+Rpm \texorpdfstring{$\sim$}{\string~} m\+Max\+Rpm})\+: Rendered in {\ttfamily m\+Over\+Color} (Default\+: Red).
\end{DoxyItemize}
\item {\bfseries{Dynamic RPM Bar}}\+: Positioned beneath the top guideline and inset by 3 pixels horizontally. Its width expands proportionately to {\ttfamily (value / m\+Max\+Rpm) \texorpdfstring{$\ast$}{*} track\+Width}. The bar\textquotesingle{}s color dynamically switches to match the active zone that the current RPM falls into.
\end{DoxyEnumerate}\hypertarget{classRpmBarDisplay_autotoc_md10}{}\doxysubsubsubsection{\texorpdfstring{Example Usage}{Example Usage}}\label{classRpmBarDisplay_autotoc_md10}

Constructs a new \doxylink{classRpmBarDisplay}{Rpm\+Bar\+Display} object with default thresholds (1100, 5000, 6000, 8000 RPM) and colors. 

Initializes the RPM bar gauge with default automotive tachometer thresholds and color schemes\+:
\begin{DoxyItemize}
\item Idle RPM threshold\+: 1100 RPM (Color\+: Blue, RGB\+: 0x00, 0x00, 0x\+FF)
\item Warning RPM threshold\+: 5000 RPM (Color\+: Green, RGB\+: 0x00, 0x\+FF, 0x00)
\item Over-\/rev RPM threshold\+: 6000 RPM (Color\+: Yellow, RGB\+: 0x\+FF, 0x\+FF, 0x00)
\item Maximum RPM scale\+: 8000 RPM (Color\+: Red, RGB\+: 0x\+FF, 0x00, 0x00)
\item Top guide line thickness\+: 5 pixels
\item Background color\+: Black (RGB\+: 0x00, 0x00, 0x00)
\item Bar groove background color\+: Dark gray (RGB\+: 0x30, 0x30, 0x30)
\end{DoxyItemize}

Internal pointers to the off-\/screen frame buffer and LCD drawing brush are initialized to nullptr.

Renders the widget background and the segmented top reference guideline. 

Renders the widget background and the segmented top reference guideline. The top reference guideline is partitioned into four colored segments proportional to their respective RPM ranges relative to m\+Max\+Rpm\+:
\begin{DoxyEnumerate}
\item Idle segment\+: width proportional to {\ttfamily m\+Idle\+Rpm / m\+Max\+Rpm}, drawn in {\ttfamily m\+Idle\+Color}.
\item Normal segment\+: width proportional to {\ttfamily (m\+Warning\+Rpm -\/ m\+Idle\+Rpm) / m\+Max\+Rpm}, drawn in {\ttfamily m\+Normal\+Color}.
\item Warning segment\+: width proportional to {\ttfamily (m\+Over\+Rpm -\/ m\+Warning\+Rpm) / m\+Max\+Rpm}, drawn in {\ttfamily m\+Warning\+Color}.
\item Over-\/rev segment\+: width proportional to {\ttfamily (m\+Max\+Rpm -\/ m\+Over\+Rpm) / m\+Max\+Rpm}, drawn in {\ttfamily m\+Over\+Color}.
\end{DoxyEnumerate}

Once all segments are rendered into the off-\/screen frame buffer, the composited background is transferred to the LCD surface.

Renders the dynamic RPM bar filled proportionally to the given RPM value.

The method performs the following steps\+:
\begin{DoxyEnumerate}
\item Computes the inner bar area with a 3-\/pixel horizontal margin on each side and vertically positioned beneath the top reference guideline (offset by m\+Topline\+Thickness + 6).
\item Clears the bar area with m\+Bar\+Bg\+Color.
\item Calculates the active bar width as {\ttfamily (value / m\+Max\+Rpm) \texorpdfstring{$\ast$}{*} total\+Width}.
\item Determines the fill brush color based on current RPM zone\+:
\begin{DoxyItemize}
\item value \texorpdfstring{$<$}{<} m\+Idle\+Rpm\+: m\+Idle\+Color
\item value \texorpdfstring{$<$}{<} m\+Warning\+Rpm\+: m\+Normal\+Color
\item value \texorpdfstring{$<$}{<} m\+Over\+Rpm\+: m\+Warning\+Color
\item value \texorpdfstring{$>$}{>}= m\+Over\+Rpm\+: m\+Over\+Color
\end{DoxyItemize}
\item Fills the dynamic bar rectangle and blits the resulting bitmap directly onto the target LCD surface at the appropriate screen coordinates.
\end{DoxyEnumerate}
