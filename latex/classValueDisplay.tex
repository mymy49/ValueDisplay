\doxysubsection{Detailed Description}
Display widget capable of rendering a formatted numeric value, unit label, title, and interactive cursor blinking. 

{\ttfamily \doxylink{classValueDisplay}{Value\+Display}} extends {\ttfamily \doxylink{classBaseDisplay}{Base\+Display}} to provide a complete, modular gauge widget suitable for instruments, sensor readouts, dashboards, and numeric input editing dialogs.\hypertarget{classValueDisplay_autotoc_md11}{}\doxysubsubsubsection{\texorpdfstring{Key Features}{Key Features}}\label{classValueDisplay_autotoc_md11}

\begin{DoxyItemize}
\item {\bfseries{Title Label}}\+: Displays an identifier string (e.\+g. "{}\+SPEED"{}, "{}\+VOLTAGE"{}) at an arbitrary position offset.
\item {\bfseries{Formatted Value}}\+: Formats floating-\/point numbers using standard {\ttfamily sprintf} format specifiers (e.\+g. {\ttfamily "{}\%3.\+1f"{}}, {\ttfamily "{}\%02.\+0f"{}}), rendered inside its own sub-\/box area.
\item {\bfseries{Measurement Unit}}\+: Displays the measurement unit suffix (e.\+g. {\ttfamily "{}km/h"{}}, {\ttfamily "{}\+V"{}}, {\ttfamily "{}°\+C"{}}) aligned at the bottom-\/left of the configured unit area.
\item {\bfseries{Cursor Blinking Support}}\+: {\ttfamily \doxylink{classValueDisplay_a26bd603b45a10759db4620b4ed2a3525}{draw\+Value\+With\+Cursor()}} enables cursor editing visualization by periodically replacing a character at a specified index with a space character when the cursor is off.
\item {\bfseries{Selective Refreshing}}\+: {\ttfamily \doxylink{classValueDisplay_a08bb1d7b3710d7c167716f3c6468d197}{draw\+Value()}} redraws only the numerical value sub-\/box, avoiding costly full-\/widget repaints on every value update.
\end{DoxyItemize}\hypertarget{classValueDisplay_autotoc_md12}{}\doxysubsubsubsection{\texorpdfstring{Example Usage}{Example Usage}}\label{classValueDisplay_autotoc_md12}

Formats the given floating-\/point value into a string using m\+Format and applies a cursor blinking effect at a specific character position ({\ttfamily index}).

If {\ttfamily on} is false and {\ttfamily index} is within the valid length of the formatted string, the character at that index is replaced with an ASCII space (\textquotesingle{} \textquotesingle{}), simulating a blinking cursor. The resulting string is then rendered into the off-\/screen frame buffer and transferred to the LCD at the widget\textquotesingle{}s value area position.
